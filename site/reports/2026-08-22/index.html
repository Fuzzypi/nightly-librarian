Worth attention

I accidentally logged hundreds of thousands of phone calls to military bases
A researcher took over abandoned ENUM nameserver infrastructure for three territories after a delegated domain expired, then discovered roughly 400,000 logged phone-routing lookups, mostly tied to Diego Garcia and Ascension Island traffic. The useful lesson is not the military angle, it is that dead telecom-adjacent DNS still carried real metadata and could have been used for call interception if the operator had answered differently. Keep this as a case study in expired upstream dependencies: if a system depends on inherited DNS or routing delegations, audit those delegations before assuming the layer is dormant.
OTel isn't going well (and I made a spreadsheet about it)
A builder audit of OpenTelemetry repo activity argues the project is slowed less by semconv debate than by thin maintainer benches and stability rules that make every feature hard to ship. The practical point is that OTel quality is not uniform across languages, so "just use OpenTelemetry" is not a real decision until you check the specific SDK and collector pieces you need. If observability work is coming, treat language coverage and maintenance depth as selection criteria, not implementation details.
How we made a text-to-speech model respond in sub-50 ms
Nari Labs published a benchmark and architecture write-up for serving Qwen3-TTS, claiming sub-50 ms p95 time-to-first-audio at 10 requests per second on a single H100 and roughly $2 per million characters at full utilization. The interesting part is less the brag line and more the serving approach: separate schedulable stages, cached codec state, and chunking tuned around playback deadlines instead of raw throughput. If voice moves closer to production work, read it for system design ideas, but treat the economics and latency numbers as vendor-run until someone else reproduces them.
Run background tasks with Celery on Vercel
Vercel says Celery background tasks now run natively on its platform for Python apps. The approved browse tool did not render the changelog cleanly, so this judgment is based on the claim snippet rather than the full page. Monitor it if Python-on-Vercel is real for you; otherwise it is a platform convenience change, not a reason to move stacks.
rust-glancer: An alternative LSP for Rust with focus on low memory usage
A Rust tooling project claims a much lower-memory language server than today's default path. The approved browse tool did not give a clean read of the linked page, so this is still headline-level evidence only. Monitor it if rust-analyzer memory pressure is already a real problem for you; otherwise wait for external validation and wider adoption signals.
