Worth attention

OpenAI releases GPT-6 Sol and Luna with ~50% lower API prices
OpenAI shipped GPT-6 Sol and GPT-6 Luna, two tiers below GPT-6 Astra. Reported API pricing is $2/$10 per M tokens for Sol and $0.10/$0.50 for Luna, about half of GPT-5.6, and OpenAI told VentureBeat these are permanent rates; prompt caching also gets higher default hit rates with up to 90% off cached reads. If you run high-volume classification, extraction or triage calls (like nightly-librarian or CalenCall summaries), re-price your cheapest tier against Luna this week.
Anthropic releases Claude Opus 5.5 at lower price
Anthropic released Claude Opus 5.5, the first of its 5.5 family, priced at $4/$20 per M tokens with cache reads cut to $0.20/M, about 40% cheaper to run than Opus 5 and 30%+ faster output. Anthropic reports it beats Fable 5.1 on agentic coding, computer use and knowledge work; it is live on the API, AWS, Google Cloud and Azure, with Sonnet 5.5 and Haiku 5.5 promised soon. If your agent/MCP pipelines run on Opus 5, swapping the model string is a near-free cost and latency win worth testing now.
tokens too cheap to meter
An essay arguing the cost of getting a task done with machine intelligence is falling by orders of magnitude per year, and working through what that does to supply and demand. It lands the same week as two big API price cuts, which makes it a useful framing piece. Worth a read if you are deciding whether to design products around token cost as a constraint at all.
FoxScript: Visual FoxPro revived on a Rust/wasm runtime (MIT)
A developer rebuilt the Visual FoxPro 9 language on a new Rust runtime compiled to wasm, checked against the real vfp9.exe, removing the 2 GB table limit, still loading old 32-bit .fll add-ins, and adding lambdas, JSON and an HTTP server. It was built for a paying customer who wanted to keep a 20-year-old business app alive; reports are unfinished and builds unsigned. Mostly interesting as a proof of the "keep legacy business apps running" market for solo builders.
Fearless SIMD v1.0 released (Rust)
Linebender shipped v1.0 of Fearless SIMD, a Rust library for portable, safe SIMD code. A 1.0 signals API stability for Rust developers who need vectorized hot paths. Only relevant if you write performance-sensitive Rust.
GPT-6 Astra reportedly breaks long-unsolved Enigma message
A cryptography-history site reports that GPT-6 Astra helped break an Enigma message unsolved since 2005. It is an interesting capability data point, but a single anecdote rather than a workflow change. Keep an eye out for how the model was actually used.
Hackers claim to have data on all FBI employees
404 Media reports a hacking group claiming to hold data on all FBI employees. The claim is attacker-sourced and not yet confirmed. No direct action for a solo developer; watch for confirmation or details on the entry vector.
