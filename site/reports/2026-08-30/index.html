Worth attention

Protecting against token theft
Vercel documented a real inference-theft attack pattern against public AI endpoints and argues that session-level auth and IP rate limits are not enough when a stolen endpoint can be resold through an OpenAI-compatible proxy. The important operational point is not the BotID pitch, it is the economics: a cheap bypass can amortize across thousands of expensive model calls unless you verify each request at the route handler. If you expose any internet-facing LLM endpoint, audit it for per-request gating, not just login walls or coarse throttles.
Protecting your Supabase projects from npm supply chain attacks
Supabase published one of the clearest recent write-ups on npm supply-chain exposure for teams using agents, and it is useful well beyond Supabase itself. The strongest parts are concrete: upgrade to a package manager with release-age gates, disable install scripts by default where possible, pin sensitive dependencies exactly, pin GitHub Actions by SHA, and treat `pull_request_target` plus PR code checkout as a live exploit path. If you maintain Node projects or let coding agents add dependencies, this is a good checklist to apply before the next routine install does the damage for you.
Function invocations now billed per unit
Vercel is changing function invocation billing from package-based pricing to per-unit pricing for Pro and new Enterprise customers at the next billing cycle. The posted rate stays economically equivalent to the old headline price, but the packaging change matters because usage now maps more directly to what you actually call rather than to a bucket. If you run workloads with spiky or team-shared invocation patterns, review your next invoice model before assuming the old included-credit behavior still tells the truth.
Team-wide provider allowlist on AI Gateway
Vercel AI Gateway added a team-wide provider allowlist that enforces approved-model vendors at the gateway layer, including Bring Your Own Key traffic. The detail worth keeping is that agent-side routing preferences cannot bypass it, and new providers stay off by default once the allowlist is enabled. If you use a model gateway to centralize compliance or spend control, this is the shape to copy even if you never touch Vercel: enforce provider policy server-side, not in developer prompts or client config.
2026-07-28 RC
The MCP project published a `2026-07-28` release candidate and explicitly reminded implementers that the spec is not final, that SDK adoption will lag, and that version negotiation remains necessary while old and new revisions coexist. That is worth attention because it is exactly the sort of protocol moment where agents and servers start failing in confusing ways if one side silently assumes the newest draft. If you build against MCP directly, keep implementations negotiable and treat this RC as a compatibility checkpoint, not a finished baseline.
RISC-V is now officially supported by CPython
CPython now officially supports RISC-V as a tier 3 platform, backed by ongoing real-hardware testing from the RISE project and a stated path toward deeper CI coverage. That does not change most laptop workflows tomorrow, but it does matter if you care about Python on open hardware, edge devices, or alternative server platforms because the support line just became materially more official. The practical move is to expect better upstream responsiveness on RISC-V bugs and to test sooner if that architecture is anywhere on your medium-term roadmap.
Sleepwalker: Passive Backdoor with Its Own Command Language
A malware-analysis write-up describes SLEEPWALKER, a passive Windows backdoor that hides until it sees a crafted trigger packet, then executes a small custom command language over covert transports including DNS and SMB pipes. The research looks credible and includes IOCs plus a scanner, but this is still an analysis post rather than a confirmed broad campaign with immediate mass-exploitation evidence. Keep it on the radar if you monitor Windows fleet security or side-loading abuse, but it is not strong enough yet for a top memo slot.
