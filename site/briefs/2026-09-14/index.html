what if my git host were a static site generator?
Charlotte Som describes sorcery, a read-only git viewer that generates static HTML for branch tips and renders historical views with a browser-side Git client. The design trades forge features for cheaper reads under scraper traffic, while an optional object endpoint reduces history-browsing round trips. It is a useful architecture reference for small public archives; consider it only when issues, pull requests, and account management are unnecessary, and benchmark your own repositories before adopting it.

Julia 1.13 highlights
The Julia 1.13 highlights describe faster collection and package operations, plus a testing change: Pkg.test no longer automatically forces strict bounds checking. That can save recompilation, but it also changes what existing tests exercise. Julia maintainers who rely on the old coverage should explicitly enable bounds checking and run their own package suite; the performance figures are project benchmarks, not results measured on this workspace.
