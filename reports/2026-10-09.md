## Worth attention

- **The Pulse: Firebase’s global outage & poor response**
  https://blog.pragmaticengineer.com/the-pulse-firebases-global-outage-poor-response/
  A backend change at Google crashed the Firebase iOS SDK, taking down every app using Firebase analytics for roughly 2-6 hours. The status page was not updated and a postmortem arrived four days later. Wrap third-party SDK init defensively and do not rely on vendor status pages for incident detection.
- **Skip sending request bodies to Routing Middleware**
  https://vercel.com/changelog/skip-sending-request-bodies-to-routing-middleware
  Vercel lets you skip sending client request bodies to Routing Middleware via a new config flag. This cuts Fast Origin Transfer usage and can improve time to first byte for large-body requests. If you run middleware on Vercel, enable it for routes that never read the body.
- **Vercel Sandbox creation now returns a ready sandbox**
  https://vercel.com/changelog/sandbox-create-waits-until-ready
  Sandbox.create() in Vercel Sandbox now resolves only after snapshot restoration completes, and startup errors reject at create time instead of on the first command. Relevant if you run agent code execution in Vercel Sandbox; check any retry/wait logic that assumed the old behaviour.
- **Step 5 Preview now available on AI Gateway**
  https://vercel.com/changelog/step-5-preview-now-available-on-ai-gateway
  StepFun's Step 5 Preview (1M-context MoE aimed at agentic coding) is now on Vercel AI Gateway and OpenRouter. No independent evals yet; track for cost versus current coding models.
- **Whistle: Speech to Text in 16.9 MB**
  https://cactuscompute.com/blog/whistle
  Whistle is a speech-to-text model packaged in 16.9 MB, aimed at on-device use. Worth a look for voice-agent work needing tiny local ASR; claims are unverified here, so benchmark accuracy and latency before relying on it.
- **A Terminal Protocol for Program Status (OSC 7501)**
  https://mitchellh.com/writing/program-status-osc7501
  Mitchell Hashimoto proposes an OSC 7501 terminal escape protocol for programs to report status to the terminal. Relevant to CLI agent tooling that wants structured status; adoption depends on terminal support, so watch rather than build on it.
